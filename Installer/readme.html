Important Information

System Requirements

  • macOS 10.15 (Catalina) or later
  • Network connection to Epilog Zing laser

Network Setup

The Epilog Zing uses the LPD protocol on port 515. Ensure that:

  • Your Mac and the Epilog are on the same network
  • The default Epilog IP is 192.168.3.4
  • Port 515 is not blocked by your firewall

Installed Components

Component Location
CUPS Filter /Library/Printers/Epilog/Filters/rastertoepiloz
Zing 16 PPD /Library/Printers/PPDs/Contents/Resources/EpilogZing16.ppd
Zing 24 PPD /Library/Printers/PPDs/Contents/Resources/EpilogZing24.ppd

Laser Safety

Warning: Always follow proper laser safety procedures when operating your Epilog Zing. Never operate the laser without proper ventilation and never leave it unattended during operation.

Print Settings

When printing, you can adjust:

  • Resolution: 100-1000 DPI (500 DPI recommended)
  • Raster Power: 1-100%
  • Raster Speed: 1-100%
  • Vector Power: 0-100%
  • Vector Speed: 1-100%
  • Vector Frequency: 500-5000 Hz
