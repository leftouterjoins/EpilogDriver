The Epilog Zing printer driver has been successfully installed.

Next Steps: Add Your Printer

1 Open System Preferences

Go to System Preferences (or System Settings on macOS 13+) and select Printers & Scanners.

2 Add Printer

Click the + button to add a new printer.

3 Select Epilog Zing

If your Epilog is on the network, it should appear in the list. Select it and choose the appropriate model (Zing 16 or Zing 24).

Alternative: Command Line Setup

You can also add the printer using Terminal:

lpadmin -p "Epilog-Zing-16" -E \
  -v lpd://192.168.3.4 \
  -P /Library/Printers/PPDs/Contents/Resources/EpilogZing16.ppd \
  -D "Epilog Zing 16"

Replace 192.168.3.4 with your laser's IP address if different.

Test Print

To verify the installation, try printing a test page from any application. Check your laser's control panel to confirm the job was received.

Troubleshooting

  • Ensure your Epilog is powered on and connected to the network
  • Check that port 515 is accessible (not blocked by firewall)
  • View CUPS logs: tail -f /var/log/cups/error_log

Uninstalling

To remove this driver from your system, double-click:

/Library/Printers/Epilog/Uninstall Epilog Driver.command

Or open Finder, press Cmd+Shift+G, paste the path above, and double-click the file.

Enjoy creating with your Epilog Zing!
